# 🗄️ SQL for QA

Repositório de estudos com consultas SQL aplicadas à validação de dados, preparação de massas de teste e apoio às atividades de Quality Assurance.

Todos os nomes, registros e estruturas utilizados neste projeto são fictícios.

---

## 📁 Estrutura do projeto

```text
sql-for-qa/
├── queries/
│   ├── select-basico.sql
│   ├── filtros-where.sql
│   ├── order-by.sql
│   ├── group-by.sql
│   ├── having.sql
│   ├── inner-join.sql
│   ├── left-join.sql
│   ├── subquery.sql
│   └── cte.sql
├── procedures/
│   └── executar-procedure.sql
├── views/
│   └── pedidos-abertos.sql
└── massas-de-teste/
    ├── clientes.csv
    ├── pedidos.csv
    └── produtos.csv
```

## 🎯 Aplicações em QA

Os exemplos podem ser utilizados para:

- Validar dados registrados pelo sistema
- Comparar resultados da interface com o banco
- Localizar massas para execução de testes
- Conferir relacionamentos entre registros
- Investigar divergências
- Apoiar testes funcionais e de regressão

---

## 🔒 Privacidade

Este projeto não contém consultas, dados, nomes de tabelas ou regras de negócio pertencentes a empresas. Todo o conteúdo foi criado exclusivamente para estudo e demonstração técnica.
