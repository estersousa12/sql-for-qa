# SQL for QA

Repositório com consultas SQL utilizadas em estudos e validações de dados para Quality Assurance.

## Conteúdos

- SELECT
- WHERE
- ORDER BY
- GROUP BY
- HAVING
- INNER JOIN
- LEFT JOIN
- Subqueries
- CTE
- Views
- Stored Procedures

## Objetivo

Organizar consultas SQL aplicadas à validação de dados, preparação de massa de testes e apoio à análise de cenários de QA.
